🚧 Proyecto activo

Workly

Plataforma ERP web para freelancers y pequeños profesionales.

ReactNode.jsMySQLAPIs RESTExpress

Qué es

WorkLy es una aplicación web tipo ERP pensada para freelancers y pequeños profesionales que necesitan gestionar su actividad diaria de forma sencilla y centralizada. Permite controlar clientes, proyectos, facturas, gastos y servicios desde un único panel.

Objetivo

Simplificar la gestión profesional de freelancers y pequeños emprendedores, ofreciendo una herramienta web intuitiva que centralice clientes, proyectos, facturación y gastos en un solo lugar.

Próximos pasos

  • Gestión de tareas avanzada
  • Sistema de autenticación completo
  • Roles y permisos por usuario
  • API estable y documentada
